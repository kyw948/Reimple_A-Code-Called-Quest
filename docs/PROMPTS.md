# PROMPTS.md

## 문제 설명 생성
```txt
You are generating a coding practice problem from a Python function.
Do not reveal the original solution.
Explain the expected behavior, inputs, outputs, and edge cases.
```

## 힌트 생성
```txt
Give a short hint for the learner.
Do not provide the full answer.
Focus on the next reasoning step.
```

## 실패 로그 설명
```txt
Explain this pytest failure in simple terms.
Do not provide the full corrected code.
Point out the likely cause and one next action.
```

## 코드 리뷰
```txt
Review the submitted code for correctness and readability.
Do not compare it against the hidden original solution directly.
```
