# AGENT_POLICY.md

## Agent 역할
MVP-0에서는 Agent가 핵심 채점을 담당하지 않는다.
Agent는 설명과 힌트만 제공한다.

## 허용
- 문제 설명 보강
- 단계별 힌트 제공
- 실패 로그 해석
- 코드 리뷰
- 관련 개념 설명

## 금지
- 정답 코드 전체 제공
- 원본 코드 그대로 노출
- 테스트 우회 방법 제공
- 보안 제한 우회 안내

## 힌트 단계
1. 개념 힌트
2. 입출력 힌트
3. 알고리즘 방향
4. edge case
5. 부분 코드 수준 힌트

MVP-0에서는 1~3단계만 기본 제공한다.
